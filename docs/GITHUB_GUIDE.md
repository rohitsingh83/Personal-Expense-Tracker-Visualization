# GitHub Setup & 6-Day Commit Plan

- **Recommended Repo Name:** `Personal-Expense-Tracker-Visualization`
- **Description:** Python & SQLite personal finance tracker with regex auto-categorization, monthly budget alerts, Excel exports, and Matplotlib charts.
- **Tags:** `python`, `pandas`, `sqlite`, `data-visualization`, `fintech`, `streamlit`, `xlsxwriter`

## 6-Day Commit Plan
1. **Day 1:** Project setup, SQLite schema (`src/models.py`), and sample bank/UPI CSV.
2. **Day 2:** Idempotent CSV ingestion (`src/ingest.py`) and regex categorization (`src/categorize.py`).
3. **Day 3:** Financial KPIs (`src/analyze.py`) and monthly budget alerts (`src/budget.py`).
4. **Day 4:** Four Matplotlib/Seaborn charts (`src/plots.py`).
5. **Day 5:** Multi-sheet Excel export (`src/report.py`) and Streamlit dashboard (`src/app_streamlit.py`).
6. **Day 6:** Unit tests, `README.md`, and interview prep docs.
